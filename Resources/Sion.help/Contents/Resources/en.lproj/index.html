Sion Help

Create diagrams and illustrations on a native canvas.

Draw

  1. Choose Rounded Rectangle, Circle, or Text in the toolbar.
  2. Click for the default size, or drag to set the frame.
  3. Choose Connector, then drag between objects or connection points.

Edit

  • Use Select to move, resize, or rotate objects.
  • Double-click text, or select it and press Return, to edit.
  • Use the Inspector for appearance, routes, and connection points.
  • Use the Library for more shapes and History to review revisions.

Save and export

Save editable work as a Sion drawing. File > Export SVG preserves vector artwork; Export Mermaid writes supported diagram structure.

Keyboard

  • Tab and Shift-Tab: select adjacent objects.
  • Arrow keys: move one point; add Shift to move ten.
  • Escape: cancel the current edit or interaction.
  • Command-S: save. Command-Z: undo.
