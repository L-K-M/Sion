Sion Help

Create diagrams and illustrations on a native canvas.

Draw

  1. Choose Rounded Rectangle, Circle, or Text in the toolbar.
  2. Click for the default size, or drag to set the frame.
  3. Choose Connector, then drag between objects or connection points.
  4. Click a tool for one use; double-click it to keep it active.

Edit

  • Use Select to move, resize, or rotate objects.
  • Double-click text, or select it and press Return, to edit.
  • Dragging an object lines it up with its neighbours; turn that off with View > Snap to Objects.
  • Resizing an image keeps its proportions; hold Shift to stretch it. Everything else resizes freely, and Shift keeps its proportions instead.
  • Use the Inspector for fill, stroke, drop shadow, routes, and connection points.
  • Use the Library for more shapes and History to review revisions.

Images

  • Drag an image from the Finder onto the canvas, or paste one.
  • An image stretches to fill its frame, so resizing crops nothing.
  • Give an image a stroke in the Inspector to frame it.

Mermaid

  • File > Import Mermaid adds a Mermaid file to the current drawing.
  • File > New from Mermaid opens a Mermaid file as a new drawing.
  • Pasting Mermaid text onto the canvas imports it where you are working.
  • Unsupported statements are kept as text, so nothing is lost.

Save, export, and print

Save editable work as a Sion drawing. File > Export SVG preserves vector artwork; Export Mermaid writes supported diagram structure.

  • File > Export Image writes PNG, JPEG, TIFF, or vector PDF.
  • PNG and TIFF can keep a transparent background; raster formats export at 1x, 2x, or 3x.
  • File > Print scales the drawing to fit one page. Use Page Setup for paper, orientation, and margins.

Keyboard

  • Tab and Shift-Tab: select adjacent objects.
  • Arrow keys: move one point; add Shift to move ten.
  • Escape: cancel the current edit or interaction.
  • Command-S: save. Command-Z: undo.
